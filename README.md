ECOSPLIT - 3MTT Capstone Project

**Author:** Salamatu Idris Shu'aibu

The Problem
In Nigeria, over 60% of youth in urban areas like Jos, Lagos, and Abuja live in shared apartments. Managing rent, NEPA bills, food, and water contributions often leads to conflict, mistrust, and financial stress due to lack of transparency.

The Solution
**EcoSplit** is a lightweight, mobile-first web application that brings transparency to shared finances. It helps co-tenants track who paid what and simplifies repayments.

Key Features
- 👥 **Create Groups & Members:** Set up your lodge or household in seconds.
- 💸 **Smart Expense Tracking:** Add expenses with category, amount, and receipt upload.
- ⚖️ **Auto Balance & Debt Simplification:** Automatically calculates equal share and reduces multiple transfers to the minimum (e.g., Instead of 6 transfers, just 2).
- 📱 **WhatsApp Export:** Share summary directly to group WhatsApp.
- 💾 **Offline First:** Works with LocalStorage, no internet needed after loading, perfect for low-data environments.
- 🧾 **Receipt Proof:** Upload image proof for every expense.

SDG Alignment
**SDG 12: Responsible Consumption and Production** - By promoting financial transparency and responsible shared consumption.

Tech Stack
- Frontend: HTML5, CSS3, Vanilla JavaScript
- Storage: Browser LocalStorage
- Hosting: GitHub Pages
- Design: Mobile-first, responsive for Android phones

How It Works
1. Create a group
2. Add members (e.g., Salamatu, Aisha, Musa)
3. Add an expense: Who paid? For what? Amount?
4. View Dashboard: See who owes, who should be paid.
5. Click Settle Up & Share on WhatsApp.
