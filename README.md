About EcoSplit
EcoSplit is a fair bill-splitting app that helps roommates, families and friends in Nigeria transparently split expenses, generate receipts, and send WhatsApp payment reminders.

Problem It Solves
Lack of financial transparency in shared households leading to conflict and debt.

Features
- Add expenses and members
- Auto-calculate fair shares
- Generate receipts
- WhatsApp reminder
- Works on mobile
